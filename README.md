## Python sentiment analyzer

Use `sentiment_analyzer.py` to score cues in a WebVTT file:

```
python3 sentiment_analyzer.py path/to/subtitles.vtt
```

The script prints per-cue sentiment (positive vs negative matches) and an aggregate summary across the whole file.
